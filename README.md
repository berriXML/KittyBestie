# KittyBestie

A cosmetic item modifier for 7 Days to Die featuring a furry feline friend who will perch upon your hat. 

Please note that this mod is still a work in progress and may continue to have some improvements (including, but not limited to the size of the visible model).

This mod requires both a server-side AND client-side download. EAC may be off OR on.
